# Find a LinkedIn profile from an email

Paste an email. When the match is exact, you get the LinkedIn name, headline, company, location, and profile URL. When it is not exact, the row comes back empty instead of a guess.

Starting from $0.60 per 1,000 emails on Gold, Platinum, and Diamond. The free plan is $2 per 1,000. Each email is processed, including a row with no exact profile.

Run it on Apify: https://apify.com/oday/mawsool-email-linkedin-lookup. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You have a mailbox and you need the person on LinkedIn.

## When to use a different Actor

You have a name and a company, and no email. Use the LinkedIn Profile Finder. You already have the profile URL and want the personal email. Use the LinkedIn Email Finder.

Mawsool is not affiliated with LinkedIn.
